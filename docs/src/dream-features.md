# What Comes Next

Threadlight is not finished. There is a lot more we want to build. This page talks about the things we hope to add one day, if we have the time and energy. None of these are promises. They are just ideas we think would be cool.

We could make tagging even better than it already is. Tags could be organized into categories like Artist, Character, General, and Rating so that finding things becomes easier. Misspelled tags could gently redirect to the correct spelling, so nobody gets lost. Tagging could even become a fun game where people earn reputation for being the first to tag a post correctly.

The database already has tables for credits and achievements, waiting to be connected to the user interface. Credits could be earned by posting, by being trusted, and by helping with moderation. You could spend them on promoting posts or creating invite-only communities for your friends. Eventually, credits could even use a tamper-evident transaction log so everyone can see that the system is fair. Streaks could reward you for visiting multiple days in a row, and gifting would let you send credits to other people as a thank-you or a kindness. Badges could appear for your first post, for reaching a certain trust level, or for being part of the community for a hundred days — little signs that say "you belong here."

The website already supports dark mode if your computer or phone is set that way, but there is no manual switch yet. We want to add a theme picker that lets you choose Light, Dark, or System, and remember your choice so you never have to set it twice.

The user interface works, but it could be much better. We want to replace the clunky page system with a proper router so everything feels smooth and fast. We want to break those enormous settings pages into smaller, friendlier pieces that are easier to understand. We want to stop swallowing errors silently and instead show them to the people who can fix them. We want loading animations and buttons that let you see more without losing your place.

One day Threadlight might speak ActivityPub, the language that Mastodon and other platforms use to talk to each other. This would let Threadlight users follow people on other servers, and vice versa, without needing a separate account everywhere. The architecture already supports it — every user already has the right kind of keys — but the actual messaging code is not written yet. It is a big dream, but it is a beautiful one.

The shared blocklist currently exists as a simple file. A future version could let trusted servers automatically share blocklists with each other, making it harder for bad actors to hop from one place to another and start over.

Most of these ideas are medium-sized. Any capable programmer could build any single one in a weekend if they had the time. The hard part is not the coding. It is deciding what to build and in what order, because every choice shapes what Threadlight becomes. If you want to help, pick the idea that excites you most and start building. That is how things get made — one person at a time, working together.
