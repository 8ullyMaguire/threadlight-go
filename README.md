# Polaris

A social platform built for positive connection — trust-based moderation, collaborative curation, and democratic self-governance. No outrage amplification. No influencer hierarchy. Just people and the things they care about.

## Quick Start

```bash
# 1. Start infrastructure
docker compose up -d

# 2. Run migrations
cat internal/db/migrations/001_initial.sql | docker compose exec -T postgres psql -U polaris

# 3. Start backend
DATABASE_URL="postgres://polaris:polaris@localhost:5432/polaris?sslmode=disable" go run ./cmd/polaris

# 4. Start frontend (another terminal)
cd web && npm run dev
```

Visit **http://localhost:5173**

## Features

- **Algorithmic feed** — personalized by mood, trust network, and tag affinity
- **Custom feeds** — build your own weighted source mix (tags + users + keywords)
- **Booru-style tagging** — any trusted user can tag any post; community-controlled taxonomy
- **Communities** — public topic spaces with curators, slow-boot, and forking
- **Auto-circles** — interest + proximity groups generated by the system
- **Community Notes** — consensus-driven misinformation warnings (Twitter/X-style)
- **Advanced search** — full boolean (AND/OR/NOT), field search, saved searches
- **Trust system** — score-driven meritocracy, no fixed levels, transparent decay
- **95% jury ban** — permanent bans require 90% jury consensus
- **Public mod log** — every moderation action is visible
- **Shared blocklist** — federated domain/IP/key blocklists
- **Credit economy** — daily rewards, gifts, bounties with 1% platform tax
- **Achievements + leaderboards** — multi-period (daily/weekly/monthly/yearly)
- **Onboarding wizard** — 4-stage guided first-run experience
- **RSS/Atom everywhere** — every feed, tag, user, collection has RSS
- **ActivityPub-ready** — actor IDs, public keys, webfinger stubs

## Stack

| Layer | Technology |
|-------|-----------|
| Backend | Go 1.26, Gin, pgx v5, go-redis, gorilla/websocket |
| Frontend | Svelte 4 + Vite (SPA) |
| Database | PostgreSQL 17 |
| Cache | Redis 7 |
| Auth | JWT (HS256) + bcrypt |
| Dev | Docker Compose |

## API

Full API reference in [AI_03_API_REFERENCE.md](AI_03_API_REFERENCE.md).  
Base: `http://localhost:8080/api/v1`  
Auth: `Authorization: Bearer <token>`

Key endpoints:
- `POST /auth/register` / `POST /auth/login` — get a JWT
- `GET /feeds` — algorithmic feed
- `POST /posts` — create content
- `GET /communities` — browse topic spaces
- `GET /search?q=...` — full-text search
- `GET /health` — Postgres + Redis health
